# 快捷键参考

本表覆盖 VelaShell 中**全部**已绑定的键盘快捷键与鼠标手势,按生效范围分组。

## 维护约定(务必先读)

**本文档不是手抄的清单,而是与代码同源的一份投影。**

- 唯一事实来源是 `src/VelaShell/ViewModels/ShortcutCatalog.cs`。设置 → 快捷键页与本文档都从它取数。
- **后续每新增或修改一个快捷键,都必须同步登记进 `ShortcutCatalog`,并把对应行补进本文档。** 这不是靠自觉:
  - `ShortcutCatalogTests.EveryMainWindowKeyBinding_IsListedInCatalog` 会扫 `MainWindow.axaml` 里的每一条 `KeyBinding`,没登记进目录就直接失败;
  - `ShortcutCatalogTests.Doc_ListsEveryCatalogEntry` 会拿目录逐条比对本文档的表格,缺行时失败信息里直接给出可粘贴的 Markdown 行;
  - `ShortcutCatalogTests.Catalog_HasNoUnresolvedResourceKeys` 保证每条文案都取到了译文,而不是在界面上显示 `Sc_Xxx` 这样的裸键名。
- 新文案键统一用 `Sc_` 前缀,并且必须**同时补齐五个 `resx`**(`Strings` / `zh-Hans` / `zh-Hant` / `ja` / `ko`),否则 `AllCultures_HaveIdenticalKeySets` 会失败。与命令面板同名的动作直接复用它的 `Cmd_` 文案键,保证两处措辞一致。
- 本表只登记**真实存在的绑定**。菜单或提示里写了、代码里却没绑的键位不得列入(历史上出现过 `Ctrl+N` 只有提示没有绑定的情况,见设置审计 C-10)。

## 绑定都写在哪

新增键位时按生效范围找对应的地方,改完再回来补表:

| 生效范围 | 实现位置 |
| --- | --- |
| 全局(窗口级) | `src/VelaShell/Views/MainWindow.axaml` 的 `Window.KeyBindings` |
| 终端上下文 + 平台差异 | `src/VelaShell/Services/KeyboardShortcutService.cs` |
| 终端控件内的剪贴板 / 翻页 / 按键编码 | `src/VelaShell.Terminal/Input/TerminalKeyRouter.cs`、`src/VelaShell.Terminal/Emulation/InputEncoder.cs` |
| 终端鼠标手势(选区、缩放、链接) | `src/VelaShell.Terminal/Rendering/VelaTerminalControl.cs` |
| 搜索栏、补全弹层、断线态键位 | `src/VelaShell/Views/TerminalTabView.axaml.cs` |
| 命令面板 / 文件管理器 / 进程管理器 / 编辑器 / 各对话框 | 各视图自己的 `OnKeyDown` |
| 停靠拖拽的 Esc 取消 | `src/VelaShell/Docking/Controls/DockDragController.cs` |
| AI 助手面板 | `plugins/VelaShell.Plugin.Ai/Ui/ChatPanelView*.cs` |

## 平台差异

全局键位在 Windows / Linux / macOS 上一律是 `Ctrl` —— `Window.KeyBindings` 没有分平台写法。

唯一的差异在**终端上下文**:`KeyboardShortcutService` 在 macOS 上把主修饰键换成 Command,于是终端内的复制、粘贴、新建标签、关闭标签与打开设置可以用 `Cmd+C` / `Cmd+V` / `Cmd+T` / `Cmd+W` / `Cmd+,`。同时 `Ctrl+C` 在三个平台都保持"发送中断信号"的语义,不会被复制抢走。

标签页切换(`Ctrl+Tab` / `Ctrl+Shift+Tab`)在所有平台都用 `Ctrl`,与终端惯例一致。

## 阅读说明

- 「生效条件」为 `—` 表示无条件生效。
- 键位里的「左键 / 右键 / 双击 / 拖拽 / 滚轮 / 侧栏 / 标题栏」是鼠标手势的组成部分,不是键盘按键。
- 同一动作出现多行,表示它有多个等效键位或在不同条件下的变体(例如回滚翻页分「主屏」与「备用屏」两种)。
